Static image assets for GOAL! Champions League Edition.

## Stadium

The game board backdrop: `stands.svg` (seamless crowd tile), `pitch-lines.svg` (pitch markings) and `goal.svg` (goal frame and net). Hand-written SVG, no photos.

## Crests

`crests/` holds one club crest PNG per club; `crests/README.md` lists the source of each file.
